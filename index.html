MSDN SQL Downloads

Dilemma

Do you have a new Corporate laptop and you've noticed your basic DB developer software was not installed or not available in the software center?

Of course - so we SSO over to MSDN and get that SQL only to find we can't open the ISO, or the EXE is blocked. Note: ISO can be mounted with zip tools (not covered here).

Why this happens... our Corporate Network Proxy (or local antivirus software) is blocking the download extension ".exe" of these files. Even though our company allows the download from the Microsoft website, the proxy or antivirus software may still block it.

Next, we just go to the public MS download for SSMS or SQL Express only to get some odd error such as "location is empty" - i.e. the download seems to start then fails. That is your Corporate Network Proxy blocking the file download.

So, it sure would be nice if someone posted a .zip for these.

Solution

  • Choose your download below
  • After downloading, unzip it
  • Rename the extracted file to include the .exe extension Note: some proxies examine file extensions — these zips are renamed binaries without the obvious .exe
